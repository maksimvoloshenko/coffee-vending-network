# C#-часть лабораторной работы №3

Перенос классов курсового проекта «Сеть кофейных автоматов» на язык C#.

## Классы

- `Ingredient` — ингредиент (кофе, молоко)
- `Recipe` — рецепт напитка
- `VendingMachine` — кофейный автомат
- `OperationLog` — журнал операций (IDisposable)
- `Money` — денежная сумма (struct)
- `Program` — демонстрационная программа

## Сборка и запуск

```bash
dotnet build
dotnet run -c Release
